# Security Policy — Chowra Logistics and Couriers Limited

## Reporting a Vulnerability

Please report security issues through the repository's GitHub Issues page:

https://github.com/venugopalareddy46/chowra/issues

Do not post passwords, API keys, tokens, private keys, or other sensitive credentials in an issue.

## Security Practices

- Keep secrets in environment variables or platform secrets.
- Do not commit real API keys or cloud credentials.
- Use HTTPS for the production domain.
- Run the production web container as a non-root user.
- Keep dependencies and container images updated.
- Review Docker and Kubernetes configuration before production deployment.

## Demo Application Notice

This repository is a technical assignment/demo application. Shipment, booking, pricing, and operational data are simulated and should not contain real customer information.
